# savings-sweep

Tells me how much of last month's pay I can move to savings on the 1st, after setting aside
every card's unpaid statement balance and upcoming payments.

```
move to savings = checking − every card's unpaid statement balance − other payments due before payday − cushion
```

- `web/calculator.html`: the phone calculator. Open it in any browser and type the balances in.
- `SPEC.md`: the build spec for a command-line version that fetches balances automatically.
  Give it to Claude Code: "Read SPEC.md and build it."
